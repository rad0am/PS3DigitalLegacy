About PS3 Digital Legacy

What this project is

PS3 Digital Legacy is a catalog of PlayStation 3 games and DLC that can only be bought digitally on the PS3 PlayStation Store. The store is expected to close, although no date is confirmed. This site helps you find what can still be bought, keep a want-to-buy list and mark what you already own.

The catalog currently lists about 900 games and 3,100 DLC. The site sells nothing and links to nothing it sells; it only informs.

Disclaimer. This is a fan project. It is not affiliated with, endorsed by or sponsored by Sony Interactive Entertainment. PlayStation and PS3 are trademarks of their respective owners. Prices are last known prices and may be out of date.

Data sources

Covers, descriptions and metadata come from IGDB. Trophy pages are on PSNProfiles. Game titles and descriptions are shown in English.

Platinum trophies

This site does not decide whether a platinum is obtainable. The PSNProfiles button only opens the game's page there, which is the source of truth.

How digital only is defined

Digital only

The game has no physical release in any region. It is shown in the default view of the catalog.

Disc release

The game itself exists on a disc in at least one region, so it is not digital only. It is hidden by default; turn off the Digital only filter to see it. A note on the game page names the region.

DLC

Always digital only, because DLC can only be bought in the store. DLC of a disc game stays in the catalog, under the DLC type and on that game's page, even while the game itself is hidden.

Help improve the catalog

Spotted a missing game, one that is gone from the store or has a disc release, or a bug? Open an issue on GitHub (a free GitHub account is needed). Each form asks for a proof link, so the entry can be checked before the catalog changes.
