About PS3 Digital Legacy

What this project is

A catalog of PlayStation 3 games and DLC that can only be bought digitally on the PS3 PlayStation Store. Use it to find what is still purchasable, keep a want-to-buy list and mark what you own.

About 900 games and 3,100 DLC. The site sells nothing.

Disclaimer. A fan project, not affiliated with, endorsed by or sponsored by Sony Interactive Entertainment. Prices are last known prices and may be out of date.

Data sources

Covers and metadata come from IGDB. Trophy pages are on PSNProfiles. Game titles and descriptions are shown in English.

Platinum trophies

This site does not decide whether a platinum is obtainable. The PSNProfiles button only opens the game page there.

How digital only is defined

Digital only

The game has no physical release in any region. Shown by default.

Disc release

The game exists on a disc in at least one region, so it is not digital only. Hidden by default; turn off the filter to see it.

DLC

Always digital only, because DLC can only be bought in the store. DLC of a disc game stays in the catalog, under the DLC type and on that game's page.

Help improve the catalog

Missing a game, or one is gone from the store or has a disc release? Open an issue on GitHub (free account needed). A proof link is required.
